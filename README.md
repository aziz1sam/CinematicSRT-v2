# 🎬 CinematicSRT v2.0 — Pro Edition

استوديو متكامل واحترافي لتحويل الفيديو والملفات الصوتية إلى ترجمات سينمائية عربية فائقة الدقة والسرعة، يدعم العمل الهجين (محلياً بالكامل على كرت الشاشة أو سحابياً بالـ API).

---

## 🌟 أبرز ما يميز الإصدار 2.0:

### 1. ⚡ سرعة خارقة بفضل تسريع كرت الشاشة (CUDA):
* يعمل **Faster-Whisper** على كرت الشاشة **NVIDIA GeForce GTX 1650** بدقة `float16` بنواة CTranslate2، مما يقلص زمن التفريغ من 19 دقيقة إلى **دقيقة ونصف فقط**.
* إدارة ذكية صارمة للذاكرة (Sequential VRAM Lifecycle): تفريغ Whisper كلياً من VRAM واستدعاء `empty_cache()` قبل تحميل نموذج الترجمة NLLB، لمنع انهيار الذاكرة على كروت 4GB VRAM.

### 2. 🌍 دعم متعدد لمزودي الذكاء الاصطناعي (Hybrid Multi-Provider):
* **Google Gemini API (الخيار الذهبي للصياغة السينمائية):** يترجم الحوار بصياغة فصحى درامية وسلسة تفهم سياق المشهد، مع الحفاظ الدقيق على الأرقام والأسماء والمصطلحات.
* **Groq Cloud API:** تفريغ صوتي سحابي فائق السرعة عبر `whisper-large-v3` في 5 إلى 10 ثوانٍ فقط، أو ترجمة سريعة عبر `Llama 3.3 70B`.
* **Local NLLB-200:** نموذج Meta المحلي الذي يعمل أوفلاين 100% بدون إنترنت داخل جهازك.
* **Local Qwen:** يدعم الربط بنموذج محلي عبر `llama.cpp` (منفذ 8080).

### 3. 🎯 دقة التوقيت والقضاء على أخطاء الـ SRT:
* القضاء التام على خطأ الـ 60 ثانية الفلكي (`00:00:60,000`) عبر حسابات دقيقة بـ `divmod`.
* منع تراكم تأخير الحوارات السريعة (Zero Cumulative Drift).
* معالجة الأسطر العربية: حد أقصى 42 حرفاً للسطر وسطرين لكل مقطع ترجمة.
* توليد صيغتين فورياً: ملف **SRT** القياسي، وملف **ASS** السينمائي الملون بخط Cairo.

### 4. 🚀 معالج التثبيت الذكي لأول تشغيل (First-Run Setup Wizard):
* عند تحميل المشروع لأول مرة على أي جهاز جديد من GitHub، يقوم البرنامج تلقائياً بفحص:
  - وجود كرت الشاشة NVIDIA ودعم CUDA.
  - وجود أداة معالجة الصوت FFmpeg (مع زر تحميل وتثبيت تلقائي بضغطة زر واحدة إن لم تكن متوفرة).
  - إمكانية تشغيل النمط السحابي الخفيف بمفاتيح API أو تحميل النماذج المحلية (Whisper / NLLB) بضغطة زر.

### 5. 🎬 مشغل فيديو تفاعلي مدمج:
* معاينة الترجمة العربية المتزامنة على الفيديو مباشرة في المتصفح قبل تنزيل الملفات.

---

## 🛠️ التثبيت لأول مرة على جهاز جديد (Fresh Clone):

إذا قمت بتحميل المشروع من GitHub لأول مرة على جهاز كمبيوتر جديد:

1. تأكد من تثبيت [Python 3.10 أو 3.11](https://www.python.org/downloads/) مع تفعيل خيار **Add python.exe to PATH**.
2. اضغط نقراً مزدوجاً على ملف:
   👉 **`setup.bat`**
3. سيقوم الملف تلقائياً بالآتي:
   - إنشاء البيئة الافتراضية `venv`.
   - فحص كرت الشاشة وتثبيت PyTorch المتوافق مع CUDA أو المعالج.
   - تثبيت كافة المتطلبات (`requirements.txt`).
   - تشغيل البرنامج وفتح المتصفح تلقائياً.
4. ستظهر لك نافذة فحص النظام تلقائياً لتختار إما إدخال مفاتيحك السحابية (Gemini/Groq) لتبدأ فوراً، أو النقر على "تحميل النماذج المحلية" للعمل أوفلاين.

---

## 🏃‍♂️ التشغيل اليومي السريع:
في المرات القادمة، ما عليك سوى النقر على:
👉 **`run.bat`**

سيعمل الخادم فوراً ويفتح الواجهة في المتصفح على: `http://127.0.0.1:8000`.

## 📁 هيكلية المشروع النظيفة (Modular Architecture):

```
CinematicSRT v2.0/
├── app.py                     # سيرفر FastAPI وخادم الـ WebSockets ونقاط فحص النظام
├── setup.bat                  # معالج التثبيت الآلي للأجهزة الجديدة
├── run.bat                    # مشغل البرنامج السريع بنقرة واحدة
├── requirements.txt           # المتطلبات الأساسية
├── core/
│   └── config.py              # إعدادات النظام وإدارة مسارات VRAM والـ API
├── services/
│   ├── audio.py               # استخراج الصوت بدقة 16kHz mono وتطبيع الصوت بـ FFmpeg
│   ├── transcriber.py         # محرك Faster-Whisper المحلي و Groq Cloud Whisper
│   ├── translator.py          # محركات الترجمة المتعددة (Gemini, Groq, NLLB, Qwen)
│   ├── subtitles.py           # مولد SRT/ASS، ضبط التوقيتات، وتقسيم الأسطر
│   ├── pipeline.py            # منسق العمليات الرئيسي، البث للواجهة، وحساب المقاييس
│   └── system_checker.py      # فحص العتاد وتنزيل النماذج و FFmpeg المحمول
├── ui/
│   └── index.html             # واجهة سينمائية حديثة داكنة مع معالج التثبيت ومشغل الفيديو
├── bin/                       # مسار FFmpeg المحمول (يتم إنشاؤه عند الحاجة)
├── uploads/                   # مجلد رفع الملفات المؤقت
├── outputs/                   # مجلد تخزين الترجمات المكتملة
└── temp/                      # مجلد مسارات الصوت المؤقتة
```
